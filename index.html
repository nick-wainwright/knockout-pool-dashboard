Odds come from The Odds API, filtered to games in the current NFL week (Tuesday-to-Tuesday) so a future week's line can't outrank this week's real options. Weather comes from Open-Meteo for outdoor stadiums only (skipped within ~16 days of kickoff isn't guaranteed — recheck close to game day). Injury status is attempted from ESPN's public data and may not always load in a browser; if it doesn't, just set it by hand from the real injury report. Nothing you enter here is sent anywhere except the two API calls needed to fetch odds and weather.
